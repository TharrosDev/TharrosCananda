# Codebase audit — September 29, 2026

The audit reviewed the authored application routes, components, domain helpers, content registries, PDF ingestion and smoke scripts, configuration, CI workflows, tests, and retained Supabase function and migration history. Fixes are on `codex/codebase-audit`. This is evidence for the local changes, not a claim that production has been deployed or that no undiscovered bugs remain.

## Fixed findings

| Priority | Finding and impact | Correction | Evidence |
| --- | --- | --- | --- |
| P1 | Both POST receivers read the entire request before applying a size limit; chunked bodies could consume unbounded memory. The readership limit also counted characters instead of UTF-8 bytes. | Shared streaming reader cancels oversized input, decodes split UTF-8 safely, and rejects malformed or broken streams. Limits remain 512 and 34,000 bytes. | Request-body, readership-route and legacy-handler unit tests. |
| P1 | The readership server did not honor the policy's Global Privacy Control promise. | `Sec-GPC: 1` returns without body processing or counting. | Route and browser-metric unit tests. |
| P2 | Readership cross-origin validation relied solely on Fetch Metadata, which is not always present. JSON MIME matching also accepted invalid suffixes. | Check Origin when supplied and compare the parsed MIME type exactly. | Route regression tests. |
| P2 | Readership counts fetched Supabase even when counting was disabled or every report was non-indexable. | Gate database reads on all required configuration and at least one approved report. Trim the database URL. | Availability tests; production build succeeds without counting. |
| P2 | Database counts were coerced blindly, allowing invalid or negative values and unknown report rows into the result. | Require nonnegative safe integers and omit unapproved slugs; hide malformed responses. | Malformed and valid response tests. |
| P2 | Overlapping browser metric submissions could race before persistence. Future timestamps could suppress counting indefinitely after a clock change. | Track pending submissions and ignore timestamps later than the current clock. Failed HTTP attempts release the pending key. | Metric concurrency, retry and dedupe tests. |
| P2 | Report asset/text lookups could return inherited properties such as `constructor`. | Require own properties in the generated registries. | Unknown and inherited-key regression tests. |
| P2 | Archive highlighting used ASCII word boundaries, breaking accented whole-word matches. Page-hit scanning repeatedly compiled the same regex. | Unicode letter/number boundaries, longest-first alternatives, and one pattern per page scan. | Unicode, whole-word, snippet and page-hit tests; archive e2e contract. |
| P2 | Fractional and non-finite PDF fragment pages could address nonexistent sheets. | Clamp to finite whole pages. | Helper tests and desktop/mobile fragment navigation. |
| P2 | PDF find results and counters could refer to the preceding query during the debounce. | Associate results with both query and render identity; clear highlights while searching. | Current-query and existing find/clear browser tests. |
| P2 | Viewer state could survive replacement of its PDF; worker destruction errors could reject unhandled. | Remount the document state by file and handle destruction failures. | Source review, rapid zoom/resize, failure recovery and worker-count tests. |
| P1 | Fullscreen overlay fallback left the surrounding page keyboard-accessible. | Dialog semantics, inert outside branches, focus containment, Escape dismissal and trigger restoration. | Desktop/mobile focus regression and existing fullscreen tests. |
| P2 | Contents links intercepted modified clicks intended to use native link behavior. | Only intercept an ordinary primary click. | Source review; normal section navigation browser checks. |
| P2 | An open mobile menu could retain its keyboard trap after resizing to desktop. | Close the sheet at the desktop breakpoint and clean up listeners. | Desktop/mobile resize regression. |
| P2 | The engaged-reader interval continued running after sending its sole event. Its observer used an unnecessary ratio threshold for a potentially tall document. | Stop the timer after sending and observe intersection directly. | Twenty-second visible reading, hidden-gap exclusion and stopped-timer unit test. |
| P2 | Provenance measurement assumed a visible client rect, and pending font callbacks could apply a stale selection. | Guard empty rects and cancel obsolete font-ready callbacks. | Source review and methodology interaction/browser accessibility checks. |
| P2 | Empty or malformed canonical URL overrides could break root metadata or generate invalid links. | Validate a bare HTTP(S) origin and fall back to the verified default. | Canonical URL unit tests; per-page metadata browser checks. |
| P2 | PDF ingestion parsed each file twice, retained worker resources, skipped zero-index bookmark destinations and assumed an uncropped, unrotated page geometry. | Reuse one document, destroy it in `finally`, accept page index zero and transform bookmark positions through the viewport. | Both real reports regenerated successfully with no changes to PDFs, covers, extracted text or manifests. Cropped/rotated inputs were reviewed in code, not tested with additional PDFs. |
| P2 | Non-indexable report social images and stable redirects lacked an explicit HTTP noindex header. | Add headers to report subroutes and stable redirects. | Local production image/redirect and PDF header browser checks. |
| P2 | `llms.txt` claimed no research existed when published reports were simply excluded from indexing. | Describe the indexing approval state accurately without listing unapproved reports. | Source review and existing indexing/content contracts. |
| P2 | Retained intake accepted malformed UUID layouts and unsafe email recipients; configuration/store network failures could reject unhandled. | Tighten payload validation and return retryable 503 responses on upstream failure. Do not reactivate the public endpoint. | Payload and mocked handler tests; Deno check; retired endpoint still returns 410. |
| P2 | The readership database function deleted unrelated expired keys on every event. | New migration atomically inserts or refreshes only the current reader's key; daily retention purge remains. | SQL review only; migration is prepared and **not applied or executed against PostgreSQL**. |
| P2 | Local Playwright could silently reuse a leftover development server. | Require a dedicated production server and update README/agent instructions. | Final e2e run built and served the production application. |
| P2 | Report instructions permitted indexing without explicit owner approval; accessibility copy referenced the retired form and overstated per-report test coverage. | Correct the intake guide and public statement, update the sitemap date, and document backend and viewer behavior. | Documentation review, core-route axe checks and desktop/mobile visual inspection. |
